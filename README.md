# 👩‍💻 Portfólio QA — Mayara Wyrla

> *"Qualidade não é um ato, é um hábito."*

Olá! Sou **Mayara Wyrla**, formada em **Sistemas para Internet** e com foco na área de **Quality Assurance**. Este repositório reúne meus estudos e projetos práticos com foco em testes manuais, testes de API e automação — aplicando boas práticas de qualidade de software.

O objetivo deste portfólio é demonstrar minha **forma de pensar como QA**: organização, capacidade analítica e conhecimento técnico, mesmo em projetos de estudo.
